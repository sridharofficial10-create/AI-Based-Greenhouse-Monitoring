# AI-Based Smart Greenhouse Monitoring and Automation System

## About the Project

GreenSense AI is a smart greenhouse monitoring and automation project developed to help monitor important environmental conditions inside a greenhouse.

The system collects information such as temperature, humidity, soil moisture, light intensity, and water level. Based on the monitored conditions, the system can support better irrigation decisions and provide useful recommendations for greenhouse management.

## Objective

The main objective of this project is to develop a simple smart greenhouse system that can monitor plant-growing conditions and automate irrigation when required.

The project also explores how IoT and AI-based recommendations can be used to make greenhouse management more efficient.

## How It Works

Sensors continuously monitor the conditions inside the greenhouse.

The sensor data is collected by the ESP32 and sent to the monitoring platform. The system can operate the water pump based on the selected control mode and the monitored soil condition.

The collected information can also be used to provide recommendations for better greenhouse management.

### Basic Working

**Sensors → ESP32 → IoT Monitoring → Data Analysis → AI Recommendations → Smart Irrigation**
